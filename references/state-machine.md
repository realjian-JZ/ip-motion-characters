# 统一状态与输入

所有角色实现同一套状态名，上层（视频脚本 / App）换角色不用改代码。

## 基础状态（每个角色必须有）

| 状态 | 类型 | 说明 |
|---|---|---|
| `idle` | 循环 | 呼吸 + 眨眼 + 眼神，永远在播；`idle@N` 为种子变体，长镜头里轮换 |
| `happy_jump` | 一次 | 原地跳，高兴 |
| `cheer` | 一次 | 双手举起 + 两次小跳 |
| `sad` | 一次 | 叹气、塌下去、回中 |
| `think` | 一次 | 手托下巴、眼睛往上看 |
| `talk` | 循环 | 嘴型 + 点头 + 一次手势；有音频时由 lipsync 覆盖嘴型 |

## 表演动作（全员）

| 状态 | 类型 | 说明 |
|---|---|---|
| `phone_look` | 一次 | 掏手机：刷屏 / 凑近眯眼 / 递出去 / 看完抬头（随 style） |
| `walk` · `walk_across[@l]` | 循环 / 一次（位移） | 原地走 / 走过画面 |
| `dance` · `floss` · `robot` | 循环 | 派对律动 / 甩胯舞 / 机器人舞 |
| `moonwalk[@r]` | 一次（位移） | 太空步滑过画面 |
| `dab` · `hero` · `peace` · `heart` | 一次 | 趣味姿势：dab / 叉腰 / 比耶 / 比心 |
| `faint` | 一次 | 晕倒 → 倒地 → 弹起 |
| `speak@<cue>` | 一次 | 口型数据驱动的说话 |

## 反诈剧情状态（按角色选做）

| 状态 | 谁用 | 说明 |
|---|---|---|
| `shock` | 全员 | 被骗 / 识破的一惊：先缩再弹，眼睛放大 |
| `alert` | 银行职员 | 抬手拦截，坚定 |
| `sneaky` | 骗子 | 东张西望 + 搓手 |

## 约定
- 一次性动作自带 入场 → 保持 → 回中，结束时回到 idle 的第 0 帧姿势，可以直接接 idle。
- 输入命名：`trigger_<state>`（一次）、`bool_talking`（说话）、`number_mood`（−1 难过 … 1 高兴，影响 idle 的眉眼）。
- 以后导出 dotLottie 状态机时，沿用这套名字。

## 串联成片（`seq@`）

剧本直接写成动作名：`seq@idle+shock+sad+idle@1`（老人被骗）、`seq@idle@2+alert+talk_x2+happy_jump`（银行职员拦截）。
- 所有段的关键帧铺到一条时间线上，段与段之间插一段过渡，用 `bridge`（正弦 in-out）曲线插值。
- 过渡时长按接缝两侧手臂姿势差自动定：0.15s 起，每差 100° 加 0.25s，上限 0.4s。
- 弹簧在整条时间线上连续模拟：头发、包、领带在接缝处不会跳。
- 某段没有的部件 / 换形组，自动回到默认值。

## 移动与位置

- `walk` 原地循环，适合配合背景平移；`walk_across` 自己在画面里走（`@l` 反方向），结束时停在另一侧。
- 在 `seq@` 里，每段动作从上一段停下的位置接着演（root.x 自动衔接），所以可以写「走进来 → 演 → 走出去」：
  `seq@walk_across+dance_x2+dab+walk_across@l`、`seq@walk_across+phone_look+shock+walk_across@l`。
