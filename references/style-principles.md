# 造型规范

学多邻国的**规律**，造型做自己的。运动规律可以学得很近，长相要拉开距离。

## 形
- 几何化：眼睛用圆角矩形，不用椭圆；头、身体都是大圆角矩形。
- 大头：头高 ≈ 身体（躯干 + 腿）高的 0.8–0.9。
- 手是连指"手套"或最多四根手指。
- 无描边。平涂 + 每种颜色最多一档暗部（同色相，明度 −10%）。
- 轮廓剪影要能一眼认出身份：靠**一个标志物**（工牌、老花镜、花衬衫、卫衣帽绳、公文包）。

## 色
- 每个角色一个主色（占画面最大面积），全系列主色互不相同。
- 皮肤、头发、眼睛、嘴的色值全系列统一，系列感来自这里。

| 用途 | 色值 |
|---|---|
| 皮肤 / 暗部 | `#FFD3B0` / `#F2B48C` |
| 眼白 / 瞳孔 | `#FFFFFF` / `#2B2233` |
| 嘴内 / 舌 | `#7A2A2A` / `#FF7D7D` |
| 腮红 | `#FF9E9E` 55% |
| 影子 | `#000000` 12% |

## 系列主色

| 角色 | 主色 | 标志物 |
|---|---|---|
| 年轻人 | 橙 `#FF8A3D` | 卫衣 + 帽绳 + 呆毛 |
| 上班族 | 灰蓝 `#5B7BA6` | 领带 + 公文包 |
| 银行职员 | 墨绿 `#2F7D6B` | 领巾 + 工牌 |
| 骗子 | 紫 `#8A4FD8` | 花衬衫 + 油头 |
| 老年人 | 暖棕 `#B9825A` | 老花镜 + 开衫 |

## 表情
- 眉毛分眉头 / 眉尾控制（旋转 + 平移）：放松、认可、疑惑、难过、生气至少 5 种。
- 嘴用换形，全系列同一套口型名（见 lipsync.md）。
