# 动作 token：曲线、分段、数值

"丝滑"不是形容词，是下面这些可以检查的数值。初始值来自经典动画规律 + 多邻国公开动画的逐帧观察，
之后每次在关口 2 被纠正，都回写到这里（并记 CHANGELOG）。

## 曲线 token（cubic-bezier）

| token | 值 | 用在 |
|---|---|---|
| `out` | 0.1, 0.6, 0.3, 1 | 上升到最高点、手臂抬到位（减速） |
| `in` | 0.55, 0, 0.9, 0.45 | 下落（加速）——重力 |
| `ease` | 0.4, 0, 0.2, 1 | 默认 |
| `inout` | 0.65, 0, 0.35, 1 | 呼吸、慢动作、来回摆 |
| `snap` | 0.2, 0, 0, 1 | 快起长收：抬手、转头、蓄力 |
| `overshoot` | 0.34, 1.56, 0.64, 1 | 到位后过冲约 10% |
| `bouncy` | 0.28, 2.1, 0.5, 1 | 过冲约 25%，年轻/弹性角色 |
| `back` | 0.36, 0, 0.66, −0.56 | 反向预备（先往回缩再出） |
| `sly` | 0.8, 0, 0.2, 1 | 慢起、猛加速、急停：油滑 |
| `hold` | — | 保持到下一个 key 再跳变（换形、眨眼） |
| `linear` | 0, 0, 1, 1 | **禁用**（机械物件除外） |

## 跳跃分段（tempo = 1 时的基准秒，实际 × `D.tempo`）

| 阶段 | 时间 | body.ss | root.y | 曲线 |
|---|---|---|---|---|
| 蓄力 | 0 → 0.18 | 1 → 1 − 0.8·squash | 0 | snap |
| 起跳 | 0.18 → 0.24 | → 1 + stretch | 0 | out |
| 上升 | 0.24 → 0.52 | → 1 | 0 → −jumpH | out |
| 下落 | 0.52 → 0.80 | → 1 + 0.7·stretch | → 0 | in |
| 落地 | 0.80 → 0.85 | → 1 − squash | 0 | snap |
| 回稳 | 0.85 → 1.16 | → 1（过冲） | 0 | settle |

手臂、头比身体晚 `lag`；腾空时腿收（±10°）；影子随高度缩小变淡（引擎自动）。

## 数值范围

- 挤压 `ss`：0.80–0.95；拉伸：1.04–1.14。超过就"果冻化"。
- 跟随延迟：2–4 帧（30fps）。0 帧 = 僵硬，> 5 帧 = 拖泥带水。
- 眨眼：闭 2 帧、睁 3 帧；idle 里 2.5–4 秒一次，偶尔连眨两次。
- 眼神：先于头 2–3 帧移动；移动用 snap，停留 ≥ 0.5 秒。
- idle 呼吸幅度 1–2%，周期 2.2–2.8 秒；整个 idle 循环 ≥ 4 秒。
- 颤动（`tremble`）：多个不同频率正弦叠加，不要单一频率。

## 弹簧（次级运动）

挂在角色上（`character.js` 的 `springs`），不写在动作里，所有动作自动生效：
`θ'' = −k·θ − c·θ' − gain·a_src`，`a_src` 为驱动源（如 `root.y`）的加速度。

| 参数 | 含义 | 起步值 |
|---|---|---|
| `k` | 刚度，频率 ≈ √k / 2π | 250–400（2.5–3 Hz） |
| `c` | 阻尼，越小晃越久 | 6–10 |
| `gain` | 对驱动的敏感度；稳态偏角 ≈ gain·a / k | 1–4（跳跃落地 a ≈ 2000 px/s²） |
| `max` | 软限幅（tanh） | 20–35° |

阻尼比 ζ = c / (2√k)：头发、帽绳 0.2–0.3（晃得欢）；手提包、公文包等有重量的道具 0.4–0.5（摆两下就停）。
道具受手臂旋转驱动时，权重 w ≤ 2，否则手一放下就甩飞。
一次性动作结束后弹簧继续模拟，渲染多出 0.5 秒收尾（`SETTLE`），让晃动在镜头里停稳。

## 自动叠加层（引擎内置，所有动作生效）

- **前臂惯性**：每条手臂自动挂一个弹簧，前臂被上臂甩动的加速度带着滞后、停下时过冲（k 320 · c 15 · gain 0.45 · 上限 14°）。
  手 K 的前臂姿势照常，惯性只是叠在上面。机械角色可在 character.js 设 `noDrag: true` 关闭。
- **转头预备**：idle 里转头前先反向转 35%，再转过去；眼睛比头早 3 帧。
- **idle 变体**：`idle@1`、`idle@2`…… 用种子决定眨眼时间、瞟眼时间与方向（奇偶种子方向交替）。
  成片里连续播放多个 idle 时轮换变体，避免整齐重复。

## 步态（walk / walk_across）

正面视角的卡通走路：腿靠「以髋为轴缩短」（leg.sy）抬起；落脚时身体最低并挤压，过渡位最高（上升 out、下落 in）；
重心压在支撑腿一侧（torso.r），头晚一拍反向歪；两臂同号摆动 = 一出一进。一步时长 P = 0.36 × tempo × step。

| style | step | 抬腿 lift | 起伏 bob | 摇摆 sway | 摆臂 | 蹲低 | 低头 | 读起来像 |
|---|---|---|---|---|---|---|---|---|
| bouncy | 0.9 | 0.20 | 9 | 2° | 14° | 0 | 0 | 蹦着走 |
| steady | 1.0 | 0.15 | 4 | 2° | 9° | 0 | 0 | 端正 |
| sly | 1.3 | 0.26 | 3 | 3° | 3° | 5 | 3 | 高抬腿蹑手蹑脚，眼睛左右瞟 |
| tired | 1.15 | 0.08 | 3 | 3° | 5° | 2 | 7 | 拖着脚、耷拉着头 |
| slow | 1.4 | 0.06 | 2 | 5° | 4° | 3 | 3 | 慢慢挪、左右晃 |

walk_across：步幅 55 × (0.6 + 0.8·energy) px；第一步加速（in）、中间匀速、最后一步减速（out）；
**root.x 的匀速段是唯一允许的 linear**（lint 已放行）。结尾 0.3s 站直（lint 抓到过：停在落脚挤压姿势）。
行走范围 ±120px：±200 时在画面边缘跳舞会把举起的手臂裁掉。

## 舞蹈与姿势

- `dance`：120 BPM（拍长 0.5s），踩拍时 snap 下沉、拍间弹起；左手 1、3 拍挥拳，右手 2、4 拍；胯与头反向摆。眼睛笑眯。
- `floss`：每拍 0.22s × tempo，8 拍一循环；两臂同向左右甩 42°，胯（root.x）反向 9px，每拍小弹。
- `dab`：蹲 → 0.13s 打到位（左臂 −110° / 前臂 −60° 横在脸前，右臂斜上 ≤ armMax）→ 头埋进肘弯、闭眼 → 还原。
- `hero`：蹲 → 弹起叉腰（上臂外展 40°、前臂内折 80°，手落在胯上）、挺胸 1.04、下巴抬起、眼神斜看。
- 以上全部 `burst`：上班族跳舞时也会突然来精神。
- `robot`：8 拍 × 0.28s。每拍 0.07s 用 `overshoot` 卡到位（锁住时的一下震动），之后 `hold`；头每拍一顿。不做挤压拉伸——僵直就是机器人感。
- `moonwalk`：root.x 全程匀速、**root.y 完全不动**（一起伏就不是太空步了）；两脚 0.08s 快速交替踮起；结尾踮脚 + 单臂甩出定格。
- `peace`：手放耳边、前臂竖直（上臂 −28° / 前臂 208°），V 字手指加粗加深描边——放在脸颊上时皮肤叠皮肤，看不见。
- `heart`：双手合于胸前 → 爱心 `bouncy` 弹出到 1.1 → 一次心跳 1.28 → 上飘 55px 并淡出。
- `faint`：身体绕脚底旋转 −85° 倒下，同时 root.x +150 / root.y −70，让身体躺在画面内、贴着地面；
  倒地用 `in`（重物下落），落地弹一下；躺着时抽一下腿；最后弹起甩头回到 idle。星星用 fx_stars 匀速旋转（fx_* 允许 linear）。

## 冲击与 Q 弹（v0.17）

**撞击是一串连锁反应，不是一帧。** 每次重落地都要检查这几件事：

| 层 | 做法 | 例 |
|---|---|---|
| 撞击定格 | 最扁的那一帧保持 2 帧（`hold` 0.066s）再回弹 | happy_jump 落地、faint 倒地 |
| 果冻形变 | 压扁 → 回弹变瘦 → 小幅再压 → 停稳（逐次减半），不要一次回到 1 | faint：1.22 → 0.9 → 1.1 → 0.96 → 1.04 → 1 |
| 自动果冻层 | 引擎内置：root 向上的加速度（起跳、落地）让身体和头额外压一下再晃回（惯性：底部先动、顶部滞后）。body k 380 / c 7.5 / gain −0.0022 / 上限 0.06；head 上限 0.06。`noJelly: true` 关闭 | 所有动作 |
| 多次弹跳 | 落地后弹 2 次，每次高度约前一次的 1/3，用 out / in（重力） | faint：18px → 6px |
| 部位错拍 | 头比身体晚一拍拍到地上，再单独压扁回弹 | faint 的 head.ss |
| 松脱物 | 挂在身上的特效（星星）撞击瞬间脱离环绕，按世界坐标抛物线飞出、落地弹一次、停在地上 | faint 星星 |
| 表情撞歪 | 撞击瞬间眉毛被撞歪（一高一低、一边斜），晕着时保持，醒来弹回 | faint 眉毛 |
| 扬尘 | 落点两侧尘土外扩、放大、淡出 0.45s；大小随体重（0.6 + 0.8·weight），踮脚角色 0.4 | happy_jump / cheer / shock / hero / faint |
| 画面震动 | 只给最重的撞击：整个 stage 衰减地震 3–4 下，约 0.16s | faint 7px |

**倒地时的贴地规则：** 侧躺时，压在下面的手脚只能往上弹、平放在地上，不能往地面方向甩（会穿地）；
上面的手撞击时甩起来、再搭到胸前。身体高度以「躯干侧面贴地」为准，影子拉长铺到整个身体下面。
