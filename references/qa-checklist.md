# 质检清单

先跑 `python scripts/lint.py`：下面标 ⚙ 的项由 lint 自动检查，0 error 才去看图。

渲染后先看 `out/<id>/<motion>/sheet.png`（每 2 帧一格），再看 gif。

## 结构（pose_test）
- [ ] 手臂、前臂转到 `rotation_range` 极限，关节处不露缝、不露底色。
- [ ] 层级：手在头前（托下巴）、袖子/后排装饰在身后，没有穿插错误。
- [ ] 挤压到 0.80 时，脸部元素不出头部轮廓。

## 动作
- [ ] ⚙ 没有线性插值；上升减速、下落加速。
- [ ] 离地前有蓄力，落地有挤压和回稳。
- [ ] 头、手臂相对身体有 2–4 帧延迟；弹簧部件在落地后还晃 2–3 次。
- [ ] 没有死帧：idle 中任意 1 秒内至少有一个部件在动。
- [ ] ⚙ 循环动作首帧 = 末帧（拼两遍看接缝）。
- [ ] ⚙ 一次性动作的末帧 = idle 首帧姿势（容差：旋转 6°、位移 3px、挤压 0.02）。

## 性格
- [ ] 遮住脸只看剪影动作，能分出是哪个角色：`python scripts/silhouette.py <motion>`。
  看 t_pk（到达最高点的时间）是否拉开、idle 的 act（动的帧占比）是否各有特点；全员同拍 = 只是换了皮。
- [ ] 同一动作横向对比 5 个角色的 contact sheet。

## 回归
- [ ] 改了引擎或模板后，全部已完成角色重渲染，sheet 逐个对比。
- [ ] 自动判定：`python scripts/regress.py`（对比上一次提交，忽略 ≤24 级的抗锯齿噪声）。本不该变的 sheet 出现 CHANGED = 被改坏了。
  不要用 `git status` 按字节比：Chrome 抗锯齿每次可能差几级，会误报。

## 道具与手
- [ ] 手里拿着东西的角色（`busyHand`），单手手势不能用那只手（道具会跑到脸前）。
- [ ] 挂件（包、吊坠）在所有姿势下保持下垂（`upright`），不跟着手臂转。
- [ ] ⚙ 举手不超过 armMax；所有口型 / 手势换形名在角色身上都存在；动作里引用的部件角色都有（`unknown-part`）。

## 撞击与 Q 弹
- [ ] 重落地的最扁一帧定格 2 帧，之后果冻回弹逐次减半，不是一下回到 1。
- [ ] 落点有扬尘，大小和体重相称；只有最重的撞击才有画面震动。
- [ ] 倒地 / 躺下：身体贴地（不悬空），下面的手脚不穿地，影子铺到身体下方。
- [ ] 撞击时挂在身上的特效（星星等）脱落飞散并落在地上，而不是继续粘在头上。
- [ ] 撞击后表情有反应（眉毛歪、嘴型变），醒来 / 回中时复原。
