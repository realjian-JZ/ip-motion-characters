# 游戏手感（Game Juice）：点击 / 放置类手游与 App MG 动效

角色动作只是一层。点击类游戏（点饼干、点怪物、点蛋……）和多邻国式 App 的流畅感，来自**同一个输入同时触发的多层反馈**，
以及**随连击不断升级**。这份规则把它们变成可以写进模板的数值。

## 1. 反馈要即时：点击不要预备

- 普通动作「预备 → 动作」；**被点击的反应没有预备**——点击本身就是预备。第 0 帧就进入最大形变（ss 0.85–0.9），之后回弹。
- 从点击到画面有变化 ≤ 1 帧（≤ 33ms）。延迟 3 帧以上手感就「黏」。
- 反应要短：0.25–0.45s。狂点时上一个反应还没放完就会被下一次点击打断，所以**任何一帧被打断都要好看**（不要在中途留怪姿势）。

## 2. 一次点击 = 多层同时反馈

| 层 | 做什么 | 时长 |
|---|---|---|
| 角色形变 | 压扁 → 回弹过冲 → 稳；头晚一拍 | 0.3s |
| 数字 | 「+N」从点击处弹出（0 → 1.3 → 1），上飘并淡出 | 0.7s |
| 奖励物 | 金币 / 星星从点击处喷出，抛物线下落或飞向计数器 | 0.6–0.9s |
| 火花 | 6–10 个小点向外散开并缩小 | 0.25s |
| 冲击环 | 圆环从点击处扩散并淡出 | 0.3s |
| 画面 | 轻微缩放冲击（stage 1.03 → 1）；大事件才震动 | 0.15s |

漏掉其中两三层，点击就会显得「没打中」。

## 3. 变化：同一个反应不能一模一样

- 每种反应准备 3–5 个变体（压扁、转圈、蹦一下、咯咯笑抖动），**随机选，但不连续重复同一个**。
- 每次再随机 ±10% 的幅度、±8° 的角度、±15% 的粒子数。人眼对完全重复极其敏感。

## 4. 升级：连击越高，一切越夸张

| 连击 | 速度 | 粒子 | 角色 | 画面 |
|---|---|---|---|---|
| 0–5 | 1.0× | 3 枚金币 | 小压扁 | — |
| 6–15 | 1.2–1.4× | 5–8 枚，加星星 | 大压扁 + 转圈变体出现 | 冲击环 |
| 16–24 | 1.5–1.7× | 10+，加爱心 | 表情变兴奋（笑眯眼） | 速度线 |
| ≥ 25 **FEVER** | 1.8× | 彩纸雨 | 改播舞蹈循环 | 背景旋转光芒、缩放冲击、数字变大变金 |

- 播放速度 = `1 + min(0.8, 连击 × 0.03)`：**狂点就是加速**。
- 连击 0.8s 没有新的点击就开始衰减；衰减要慢于上升（不要一停手就打回原形）。
- 数字随连击增大字号和数值（+1 → +2 → +5 → +10），FEVER 时变金色。

## 5. 奖励要「流向」计数器

金币不只是炸开然后消失：炸开后在 0.3s 内转向、加速飞向界面上的计数器，到达时计数器自己弹一下（scale 1.15 → 1）。
这让玩家觉得「我拿到了」。

## 6. 没人点的时候要邀请点击

- 空闲 3–5s 后播放「邀请」动作：角色朝屏幕方向弹两下、眨眼、身边闪一个亮点（`beckon`）。
- 不要一直跳——邀请动作之间留出完整的 idle。

## 7. 其他常用的 MG 表达

- **顿帧（hit-stop）**：重击时冻结 1–2 帧，再继续。
- **拖影 / 速度线**：快速位移时在运动方向反侧画 3–5 条线，0.15s 淡出。
- **光芒（rays）**：奖励、升级时背后一圈旋转的放射形，缓慢旋转（fx 部件允许匀速 linear）。
- **弹出（pop-in）**：任何新出现的元素都从 0 放大过冲到 1（bouncy），不要直接出现。
- **呼吸感的 UI**：按钮、计数器也有轻微的呼吸缩放，整个画面都是「活」的。

## 在本 skill 里的对应

- 引擎粒子层 `engine/fx.js`：coin / star / heart / spark / confetti / ring / text / lines / rays，按种子确定性生成（渲染可复现）。
- 模板：`tap@1..4`（四种点击反应）、`beckon`（邀请点击）、`fever`（6 秒连点加速到 FEVER 的完整演示）。
- 试玩页 `play.html`：真的可以点——连击加速、粒子、计数器、FEVER 模式。
